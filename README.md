# Biblioteca
> *"La biblioteca es ilimitada y periódica."* — Jorge Luis Borges, *Ficciones* (1944)

Very much thanks to DeepSeek-v4.1-flash. She fixed all the bugs I found.

See more info at modrinth.md under root dir.

The multi-version build matrix (1.20.4 – 26.3) and its current porting status
are described in [PORTING.md](PORTING.md). The default build emits seven grouped
jars in `build/grouped/`; the legacy renderer is ported for the exact 1.21.1
and 1.21.8 nodes and remains in progress for the other legacy releases.
