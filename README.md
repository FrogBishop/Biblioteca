# Biblioteca
La biblioteca es ilimitada y periódica. --*Ficciones*, 1944, Jorge Luis Borges

This mod rewrites the y-axis to make it act like a ring. No lowest, no highest, only loop. It's an attribute of a dimension.

Void fog is deleted in those dimension with this attribute.

Thanks to stupid Claude, render system is totally broken. Besides, there are millions of block-associated bugs. But it's pretty cool.
